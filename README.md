# 手写作业生成器 · 本地版

对标「凹凸工坊」的本地纯前端手写稿生成器。**双击 `index.html` 即用**，不联网也能跑，无卡密、无会员、无次数限制，文字不上传任何服务器。

## 快速开始

**方式一 · 轻量版（推荐，分享给别人用这个）**：`dist-lite/手写作业生成器.exe` —— **就一个文件，约 131 MB，拷给别人双击即用**。
- 不捆绑 Chromium：直接用 Windows 自带的 Edge WebView2 内核，所以体积小、启动快。
- 首次运行自解压到 `%LOCALAPPDATA%\手写作业生成器\`（约十几秒），之后每次 2 秒内开；重装/换电脑只需再发这一个 exe。

**方式二 · 浏览器版**：双击 `index.html`（推荐 Chrome / Edge / 夸克）。

两者界面与功能完全一致，都纯本地运行。接着：

1. 输入或粘贴文字 →（可选）导入 Word / 图片 → 选字体、纸张 → 拖三个「凌乱度」滑块。
2. 点 **⚡ 生成预览**，满意后点 **📥 下载 PDF（高清）**。

> 想更像真人手写？把「随机勾画涂改概率」调到 3~8，「文字位置凌乱度」10~25，「字体笔画凌乱度」5~20，并试试不同的「种子」多生成几版挑最像的。

## 功能

| 模块 | 说明 |
|---|---|
| 文字输入 | 直接粘贴文字；也支持导入 **Word(.docx)**、**TXT**、**图片(OCR)**（后两者联网按需加载库） |
| 字体 | **只用手写字体**，且**中英文分开选**：中文 9 款 + 英文 18 款内置手写体（随程序分发，按需加载）+ **可载入任意本地 .ttf/.otf** |
| 纸张 | 常用纸张常驻；低频纸张（米色/牛皮/做旧纹理、草稿纸、A4/B5/A3 打印纸）折进 **「更多纸张」**，点开即用、不占版面。**每张纸都能删**（卡片右上角 ×）；**自定义上传**的纸张可勾选 **「长期保存」** 跨会话留住，上传也是拖拽即用 |
| 凌乱度 | 随机勾画涂改概率、文字位置凌乱度、字体笔画凌乱度（0-100，带推荐值） |
| 墨水 | 真实笔色预设（黑色中性笔 / 蓝黑墨水 / 蓝色直液笔 / 铅笔HB / 红色批改笔）+ 自定义取色 + **逐字深浅微变**（同一墨色，仅笔画轻重略有差别，不会偏色）+ 加粗 |
| 导出 | PNG（150/300/600 dpi，**清晰版**）、**导出预览图**（所见即所得，导出与预览观感一致的柔和版，更像真实手写照片）、**零依赖生成的多页 PDF**、打印。导出时由系统弹出**「另存为 / 选择文件夹」**对话框，自己选存哪（单页选文件、多页选文件夹），不再触发浏览器「下载多个文件」的拦截 |
| 逐行微调 | 生成后点 **逐行微调** 可拖着某一行任意挪位，**能拖到上一页 / 下一页**（把第 1 页的内容拖到第 2 页也行，不会拖出当页就消失）；空白处框选或多选后整组一起拖；支持撤回 / 重做（前后各 10 步）。微调结果**预览即所得**，导出与打印同步 |
| 复现 | 固定「随机种子」可精确复现同一份手写效果；草稿存本地浏览器 |
| 更新提醒 | 启动后静默查一次 GitHub 最新 Release（**6 小时最多查一次**，离线/被限流静默跳过）。有新版时右下角弹卡片，点「去下载」用系统浏览器打开 Release 页。已忽略的版本不再打扰 |

## 桌面版打包

**轻量单文件（推荐）**——无需装 Node，只要 Windows 自带的 .NET Framework：

```powershell
powershell -ExecutionPolicy Bypass -File build-lite.ps1
```

产物 `dist-lite/手写作业生成器.exe`：`launcher/App.cs`（WebView2 外壳）编译后，把 `index.html/js/css/fonts` 压进 exe 尾部；程序启动时按载荷内容指纹决定是否重新自解压。改完页面重跑此脚本即可，用户端会自动重新解压。

**Electron 版（重型兜底，不依赖 WebView2）**——需要 Node：

```bash
npm install                 # 首次：装 electron / electron-builder（已配 .npmrc 走国内镜像）
npm run dist                # 出便携版 + 安装版两个 .exe，产物在 dist/
npm run start               # 开发模式：直接开桌面窗口调试
```

`npm install` 若卡在 Electron 二进制下载（国内网络），手动补一刀：

```bash
ELECTRON_MIRROR=https://registry.npmmirror.com/-/binary/electron/ node node_modules/electron/install.js
```

## 字体（fonts/handwriting/）

**项目只用手写字体**，且**中文和英文各有独立的一栏、各自选一种**（正文里中文字、标点、以及中文标点走「中文」字体；拉丁字母和数字走「英文」字体）。已删去原来的印刷体/系统字体。手写体来自两个免费商用字体站，已下载并本地化，**双击即用、离线可跑**：

- **找字网 zhaozi.cn**「免费商用」专区 —— 保留 4 款中文手写（小箱子荣耀体、寒蝉手拙体、王强手写体、鸿雷板书简体）；其余同站字体（道须/851马克笔/刻石录钢笔鹤/衡山毛笔/英椎行楷/汉仪贤二/cjkfonts 等）因**只覆盖繁体或常用简体字不全**，会让「部分字回落系统字体」，已剔除
- **洋芋田 potatofield.cn**字体库 —— 保留 1 款中文手写（千图笔锋手写体）+ 10 款英文手写（Pippa Handwriting、Brusher、Simple Script、Signatura Monoline、Playlist Script、Cute Aurora、Kalmansk、One Day、Zhiyong Write 等，**Magiera Script 因缺 `-()` 标点已剔除**）
- **我的定稿**：中文「悠哉手写」+ 英文「Kalam」（即「手写稿一键生成」工具用的那两款）
- **新叶念体**、**平方韶华体**、**栗壳坚坚体**：另三款全简体覆盖的手写体

> ⚠️ 全部 9 款中文字体均已实测**常用字 100% 覆盖**（个别字体缺 `·…°～` 等稀有符号），保证「选中哪款，全部字就是哪款」，绝不回落系统字体。

> ⚠️ 字体版权归各版权方所有，各站标注「免费商用」但商用前请自行核对授权。渲染引擎会**按需加载**——中文字体每款 3~25MB，只有选中时才拉取，不会一次加载两百多 MB。

## 技术要点

- **纯前端零依赖**：无构建、无 npm、无 CDN 依赖（Word/OCR、更新检查才按需联网）。因此可以直接 `file://` 打开，不受 CORS 限制。
- **排版**：全部用毫米(mm)坐标，导出时按 dpi 缩放；格子纸以「半格」为步进支持中英混排；内置中文**避头尾**（标点不在行首、开括号不在行尾）。
- **手写真实感**：每行整行基线缓慢漂移 + 每字独立微抖 + 笔画形变(缩放/旋转/切变) + 墨迹阴影渗透；涂改/勾画按概率随机出现。
- **可复现**：布局与页码各用独立种子的 mulberry32 随机流，同种子必然得到同一结果。
- **PDF**：自实现的极简 PDF 写入器，把每页 Canvas 以 JPEG 嵌入，无任何第三方库。

## 想加更多字体

把任何 `.ttf/.otf` 丢进界面里「载入本地字体文件」即可临时使用；或放进 `fonts/handwriting/cn|en/`，在 `js/catalog.js` 的 `FONTS` 表加一行（`kind:'bundled'`、`file` 路径、`family:'HW_xxx'`）即可长期使用。发布分发时请自行确认字体授权。

## 合规提醒

本工具仅用于**生成图像/打印**。把 AI 生成的“手写稿”当作真实手写提交属于个人诚信与所在机构规定的问题，请自行判断使用场景。中间任何环节都不涉及自动化操作或绕过任何平台。
